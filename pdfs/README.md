# PDF Files Directory

This folder is where you should place PDF files for the AI Supplier Agent to process.

## Usage:
1. Copy your supplier/product PDF documents to this folder
2. Run the agent: `python run.py`
3. The agent will automatically scan this folder for PDF files

## File naming suggestions:
- `supplier_invoice_001.pdf`
- `product_catalog_2024.pdf`
- `price_list_december.pdf`

The agent will process all `.pdf` files found in this directory.
